## Codebase Patterns
- EventStream consumption: `use adk_rust::futures::StreamExt;` then `stream.next().await` in `tokio::select!` with `ctrl_c()` for cancellation — `event.is_final_response()` is the break condition
- adk-rust 0.7.0 is the current version (PRD said 0.6.0 but that doesn't exist — use 0.7.0)
- adk-rust `"sessions"` feature does NOT include sqlite — must add `adk-session = { version = "0.7.0", features = ["sqlite"] }` separately in Cargo.toml
- adk-rust features for providers: only `anthropic` and `gemini` are direct features. For openai/deepseek/ollama/groq/openrouter, use `adk-model` crate directly with its features
- **Import pattern for adk-model providers**: `use adk_model::anthropic::{AnthropicClient, AnthropicConfig}` etc. — NOT from `adk_rust::prelude::*` (prelude re-exports are gated by adk-rust features, not adk-model features)
- `adk_rust::prelude::Llm` trait is always available from adk-core
- **adk-rust types re-exported**: `adk_rust::ToolConfirmationPolicy`, `adk_rust::ToolConfirmationDecision`, etc. (via `pub use adk_core::*`)
- `dotenvy::dotenv()` is called in `cli/mod.rs` at startup — .env file loading is already wired up
- reqwest 0.13 TLS feature is `rustls` (not `rustls-tls` as in older versions)
- path-clean 0.1 takes `&self` reference, not owned PathBuf
- Borrow checker: clone provider/model strings before mutable borrow when switching providers
- All "never used" warnings are expected for placeholder code in scaffold phase
- Each tool module (file, shell, search) has its own `thread_local!` sandbox context — register via `set_sandbox()` in `build_tool_registry()`
- Edition 2024 implicit borrow: use `if let Some(x)` not `if let Some(ref x)` when matching on reference types
- **Rust Edition 2024 raw strings**: `r"..."` CANNOT contain `"` — must use `r#"..."#` or `r##"..."##`
- **Rust Edition 2024 guarded strings**: `"#"` triggers "unprefixed guarded string literal" — use `std::iter::repeat('#').take(n).collect::<String>()`
- **Regex patterns with `"`**: always use `r#"..."#` or `r##"..."##` delimiters — a single broken raw string causes cascading parser errors across the whole file
- **Always fix the FIRST compiler error first** — subsequent errors are often cascading from the first one
- **macOS symlink**: `/var` → `/private/var`, `/tmp` → `/private/tmp` — always `canonicalize()` before comparing paths with `starts_with()`
- **ignore crate**: use `GitignoreBuilder::add_line(None, pattern)` for programmatic loading, NOT `OverrideBuilder` or `GitignoreBuilder::add(path)`
- **Sandbox `.agentignore`**: loaded from non-canonicalized root path (before `canonicalize()`), then root is canonicalized — this ensures the file is found via its original path

### adk-rust 0.7.0 API Reference (verified from source)

**Tool creation via #[tool] macro:**
- Signature: `async fn name(args: ArgsType) -> Result<Value, AdkError>` or with ctx: `async fn name(ctx: Arc<dyn ToolContext>, args: ArgsType) -> Result<Value, AdkError>`
- Args type must impl `Deserialize` + `JsonSchema` (from schemars crate)
- Doc comment becomes tool description. Generates zero-sized struct in PascalCase
- Attributes: `#[tool(read_only)]`, `#[tool(concurrency_safe)]`, `#[tool(long_running)]`

**Tool creation via FunctionTool::new():**
- `FunctionTool::new("name", "description", handler_fn).with_read_only(true).with_parameters_schema::<ArgsType>()`
- Handler: `async fn(Arc<dyn ToolContext>, Value) -> Result<Value>`

**Provider constructors (from adk-model):**
- Anthropic: `AnthropicClient::new(AnthropicConfig::new("key", "model"))?`
- OpenAI: `OpenAIClient::new(OpenAIConfig::new("key", "model"))?`
- DeepSeek: `DeepSeekClient::chat("key")?` or `DeepSeekClient::reasoner("key")?`
- Groq: `GroqClient::new(GroqConfig::new("key", "model"))?`
- Ollama: `OllamaModel::new(OllamaConfig::new("llama3.2"))?`
- OpenRouter: `OpenRouterClient::new(OpenRouterConfig::new("key", "model"))?`
- Custom: `OpenAICompatible::new(OpenAICompatibleConfig::new("key", "model").with_base_url("url").with_provider_name("name"))?`
- Convenience: `adk_rust::provider_from_env() -> Result<Arc<dyn Llm>>`

**LlmAgentBuilder (from adk-agent):**
- `LlmAgentBuilder::new("name").model(Arc::new(model)).instruction("system prompt").tool(Arc::new(tool)).build()?`
- Key methods: `.description()`, `.temperature()`, `.max_output_tokens()`, `.max_iterations()`, `.tool_timeout()`, `.before_tool_callback()`, `.after_tool_callback()`, `.tool_confirmation_policy()`, `.require_tool_confirmation("name")`, `.sub_agent()`

**Runner (from adk-runner):**
- `Runner::new(RunnerConfig { app_name, agent, session_service, ... })?` or `Runner::builder().app_name("x").agent(arc).session_service(arc).build()?`
- Run: `runner.run(user_id, session_id, content).await?` returns `EventStream` (Pin<Box<dyn Stream<Item = Result<Event>>>>)
- Interrupt: `runner.interrupt("session-id") -> bool`

**SqliteSessionService (feature: `sqlite` on adk-session):**
- `SqliteSessionService::new("sqlite:///path/to/db").await?` then `service.migrate().await?`
- Needs `adk-session = { version = "0.7.0", features = ["sqlite"] }` — NOT included in adk-rust standard feature

**Key types (from adk-core):**
- `Content::new("user").with_text("message")`, `Part::Text{text}`, `Event{id, author, llm_response, actions}`
- `LlmRequest::new(model, contents)`, `LlmResponse{content, usage_metadata, finish_reason}`
- `EventStream = Pin<Box<dyn Stream<Item = Result<Event>> + Send>>`
- `use adk_rust::prelude::*;` for all common types
