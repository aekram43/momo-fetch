# Brand Usage Guide

## Palette

The brand has two colours, both sampled from `brand/source/brand-sheet.png`:

| Colour | Hex | Where it goes | Notes |
|---|---|---|---|
| **Navy** | `#061a2b` | App background, text in light mode | The brand's primary colour. Used as `--void` in dark mode and as text `--ink` in light mode. |
| **Orange** | `#f76915` | Agent state signals only | See section below. |

## The accent colour and state signals

The design system reserves one colour to mean "the agent is working, or wants something from you." The brand has exactly one accent. **The brand orange is the state colour** — it is not a decorative accent.

On dark backgrounds, `#f76915` clears WCAG AA contrast (5.87:1), so it carries meaning and can reliably signal state changes. On light backgrounds, this contrast fails (3.05:1), so it is darkened to `#bf4605` (4.83:1) to keep it readable and preserve its meaning as a signal rather than decoration.

**Never use the brand orange except as the state signal.** A permanently orange element on screen — like an orange wordmark in the corner — is a standing false alarm and blunts the colour everywhere it actually carries meaning.

## The wordmark

The MOMO WORK lockup in the app (top left, next to the mark) is **not painted in the brand orange**, even though the full-colour brand lockup is. The mark keeps its orange bone — a small unmistakable part that identifies the logo. The words take the ink colour instead (navy in light mode, light grey in dark mode). This avoids making a standing false alarm out of the wordmark.

Full-colour lockups belong where the brand *belongs* — the app icon, installer packaging, marketing, the website — not in the running interface where one colour must mean "attend to this."

For details, see the comment in `web/src/components/shared/wordmark.tsx`.
