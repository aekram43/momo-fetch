# LLM can serve as the semantic engine instead of vector embeddings

For personal agent memory (<1000 notes), the LLM itself can judge relevance
of grep candidates, eliminating the need for a vector database.
This follows Andrej Karpathy's "LLM-wiki pattern" approach.

**Evidence**: Four retrieval modes designed (grep_llm, graph_walk, tag_filter, agentic)
that rely on grep for candidate generation and LLM for relevance ranking.
