# Obsidian wiki can replace PostgreSQL for personal agent memory

The EverMemOS 6-level memory hierarchy (MemCell, Event, Foresight, Episode, Profile, Reflection)
can be implemented using Obsidian-style markdown files with frontmatter and wikilinks,
replacing the need for PostgreSQL + pgvector + Elasticsearch + Milvus.

**Evidence**: Schema designed and validated against EverMemOS codebase. grep + LLM retrieval
is sufficient for personal-scale memory stores (<100K notes).
